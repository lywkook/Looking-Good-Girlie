這個 App 幫你什麼?
記錄每天吃了什麼、喝水、體重,還能幫你規劃減重菜單與運動,拍照就能估熱量。

怎麼開始?
① 點上面的計畫卡片進入,或用下方「＋ 建立新計畫」
② 進去後就能記錄飲食、喝水、體重

想用「拍照估熱量」和「AI 運動規劃」?要先貼一把免費金鑰(一次就好):

  1. 到 Groq 申請(推薦,額度高、也能看圖);或 Google。都是免費、免信用卡
  2. 登入 →「Create API key」→ 複製那串金鑰
  3. 回到 App,進入任一計畫 → 「飲食紀錄」裡的「🔑 AI 金鑰設定」→ 貼上 → 儲存
  4. 之後拍照估熱量、換菜單、運動規劃都能用了

換背景 / 顏色?
主畫面按「🎨 主畫面外觀」;每個計畫進去後按下面「⚙️ 設定」,可以各自換。

你的資料只存在自己這支手機的瀏覽器,不會上傳,換手機或清除瀏覽器資料就會不見。
