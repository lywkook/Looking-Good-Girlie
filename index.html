這個 App 幫你什麼?
記錄飲食、喝水、體重,規劃減重菜單與運動,拍照估熱量。

怎麼開始?
① 點上方計畫卡片,或用「＋ 建立新計畫」
② 進入後記錄飲食、喝水、體重

使用拍照估熱量與 AI 運動規劃前,先貼一把免費金鑰:

  1. 到 Google 申請(推薦:拍照估熱量、運動照片、讀菜單照片都最穩);想要更高額度也可用 Groq。都是免費、免信用卡
  2. 登入 → Create API key → 複製金鑰
  3. 回到 App → 任一計畫 →「飲食紀錄」的『AI 金鑰設定』→ 貼上 → 儲存
  4. 之後即可使用拍照估熱量、換菜單、運動規劃。

換背景 / 顏色?
主畫面與各計畫外觀可在「⚙️ 設定」分別調整。

資料只存在本機瀏覽器,不會上傳;換手機或清除瀏覽器資料會遺失。
