# Looking Good Girlie

本來只是想幫朋友記一下飲食跟體重，結果功能越加越多就變成現在這樣了。一個減重用的小工具，記吃的、喝的、體重，順便讓 AI 幫忙排菜單跟運動。

手機瀏覽器打開就能用，不用下載、不用註冊，東西都存在自己手機裡，不會傳去別的地方。

網址：<https://lywkook.github.io/Looking-Good-Girlie/>

## 開始用

打開網址就是了。想放到桌面當成一般 App 用，就在 Safari 或 Chrome 按「加入主畫面」。

第一次進來先建一個計畫 — 可以只單純記錄（飲食＋喝水＋體重），也可以讓它幫你規劃減重減脂。之後每天回來記就好。開過一次之後沒網路也能用。

要注意的是，所有紀錄只在這支手機的瀏覽器裡，換手機或清掉瀏覽器資料就會不見，重要的話記得用匯出 PDF 存一份。

## 畫面大概長怎樣

最上面可以切換計畫（有多個計畫的話點名字會跳出來選）跟切換日期。底下分成三個分頁：

- **飲食** — 今天要吃什麼、吃了什麼都在這。今日菜單會自動給早午晚點心的建議，不喜歡就點鉛筆改，或按「更改菜單」讓 AI 重配、也可以拍餐廳菜單叫它從裡面挑一道適合減重的。往下是飲食紀錄，記今天吃了什麼、還剩多少熱量可以吃；懶得算熱量就拍張食物照片讓它估。再下面還有「冰箱有什麼、煮什麼」跟喝水紀錄。
- **運動** — 每日打卡跟運動計畫。跟它說一週想練幾天、手邊有什麼器材，它會排一週課表；看到喜歡的動作也可以拍照讓它加進去。
- **數據** — 記體重、體脂、肌肉，自動畫成趨勢圖跟目標線。也可以把體重計 App 匯出的 CSV 直接匯進來。

## 幾個比較好玩的功能

**AI 教練** — 按「根據今日身體數據，重新調整菜單&運動」，它會把你最近吃的、動的、量到的數據，連同目標跟期限一起看，再幫你重新調今天的菜單跟運動方向。如果它算出來該練的天數跟你原本設定的不一樣，會先問你要不要接受，不會自己亂改。

**拍照估熱量** — 選好是哪一餐，拍張照，辨識完直接加進當天紀錄。份量可以填小數或分數（像 0.5、1/4），熱量會跟著重算。

**菜單跟飲食紀錄可以互相對調** — 可以把今天排好的菜單一鍵倒進飲食紀錄，或反過來拿你實際吃的去更新菜單。

**冰箱煮什麼** — 填一下冰箱現有的食材，它推薦幾道能做的家常菜，這也會影響換菜單時的建議。

## AI 功能需要一把免費金鑰

估熱量、換菜單、讀菜單照片、排運動這些都要串 AI，所以需要一把免費金鑰：

到 [Google AI Studio](https://aistudio.google.com/apikey) 申請一把（拍照跟讀菜單照片這把最穩），想要額度更高也可以改用 [Groq](https://console.groq.com/keys)，兩個都免費、不用綁信用卡。拿到之後回 App → 右上角設定 → 最上面貼上就好，金鑰只會存在你手機裡。

沒有金鑰也能用，換餐這類功能會改用內建的建議清單，只是沒那麼聰明而已。

## 其他

設定裡面還能填個人資料跟目標、開提醒（可以匯出成手機行事曆每天定時提醒你）、換主題色跟背景、調字體大小、換字體（有粗線體、紅豆奶霜體、初夏絮語體三款），也能把整個計畫匯出成 PDF。想全部重來的話也有清空按鈕。中文 / English 可以一鍵切換，連匯出的 PDF 都會跟著換語言。

## 傳給朋友

直接把網址傳過去就好，每個人打開都是自己的空白紀錄，互不干擾。想要一份乾淨的空白版本，網址後面加上 `?blank`。
